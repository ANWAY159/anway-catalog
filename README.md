# Anway 产品选型站（Product Finder）

把安规现有的 **62 个型号 / 8 个系列**做成一个手机优先的产品目录：搜索、筛选、中英切换、离线可看，能发布到 GitHub Pages，手机上「添加到主屏幕」后像 App 一样全屏打开。

---

## 一、现在就能看

双击 `site/index.html` 即可（Chrome / Edge / 手机浏览器都行）。

- 首页：**四步快速选型**（功率 → 调光方式 → 功能 → 输出），每步显示剩余数量，结果就地展开；顶部是系列快捷入口
- 型号页：搜索 + 系列筛选 + 调光/功率/认证筛选 + 排序
- 详情页：完整参数、典型应用、复制参数、分享链接、加入样品清单
- 样品需求：选型 → 加入清单 → 填信息 → 邮件 / 企微 / 复制发送
- 右上角 `EN / 中文` 切换语言；深色模式跟随系统

> 本地双击打开时地址栏不写参数（浏览器的 file:// 安全限制），其余功能不受影响。

## 二、文件说明

```
site/                     ← 整个目录就是要发布的内容
  index.html              页面骨架
  app.js                  全部逻辑（无依赖、无构建）
  styles.css              样式（浅色 / 深色）
  data.js                 型号数据（自动生成，页面读这个）
  data.json               同一份数据的 JSON（给别的程序用）
  sw.js                   离线缓存
  manifest.webmanifest    PWA 配置（添加到主屏幕）
  icons/                  图标（自动生成）
    wecom-qr.png          企微二维码（已换成真码；要更换直接覆盖这个文件）

tools/
  build_catalog.py        从 xlsx 生成 data.js / data.json
  make_icons.py           生成图标
  make_selector_xlsx.py   生成「选型维度.xlsx」模板

选型维度.xlsx              ← 首页四步选型的配置表（改这个就能调选型维度）
```

## 三、改数据

1. 修改 `anway_dali_report_2026-11/…产品矩阵与路线图_2026-11.xlsx` 的「产品矩阵」工作表
2. 运行：

```powershell
python tools/build_catalog.py
```

3. 刷新页面即可

**公开版 / 内部版**

| 命令 | 内容 | 用途 |
|---|---|---|
| `python tools/build_catalog.py` | 不含「市场位置 / 差距建议 / 优先级」三列 | 对客户、发布到公网 |
| `python tools/build_catalog.py --mode internal` | 含内部三列 | 内部看；页面顶部会出现红色「内部版 · 请勿公开发布」横幅 |

> 内部版不要上传到公开仓库。GitHub Pages 免费版要求仓库公开。

## 三之二、调整首页「快速选型」（选型维度.xlsx）

首页那三步（功率 / 控制方式 / 输出）完全由根目录的 `选型维度.xlsx` 决定：

- 改完保存 → 双击 `3_一键更新数据.bat` → 上传三个文件，**不用改代码**
- 同一个「步骤ID」的行归为同一步；步骤先后 = 表格里第一次出现的顺序
- 加选项：复制一行，改选项ID、中英文名称、筛选条件
- 加新的一步（比如「认证」）：新写一个步骤ID，填它的若干选项行
- 删掉某行 = 前台不再显示该选项
- 每个选项后面的数量是**自动算**的，表格里不用填
- 现在「DALI」显示 0：矩阵表里还没有 DALI 型号。等有产品了，这行数字会自动变，不用改配置

筛选条件写法（`&` 同时满足，`;` 满足任一）：

| 写法 | 含义 |
|---|---|
| `power_min<=10` | 功率下限 ≤10W |
| `power_max>=60` | 功率上限 ≥60W |
| `tag=wireless` | 含无线（wireless / triac / switch / touch / none / dali） |
| `category~恒流` | 类别含“恒流” |
| `cert~ENEC` | 认证含 ENEC |
| `channels~CCT` | 双色温 |
| `topo=CC` / `topo=CV` | 恒流 / 恒压 |
| `cct=1` / `ctrl=1` | 是双色温 / 是控制器 |
| `series=eco` | 只看某系列（as-cc / as-cv / asc / eco / hw03 / aw02 / plugin / light） |

## 四、发布到 GitHub Pages（不用装 git）

1. 打开 github.com → 注册/登录 → **New repository**
   - 名称例如 `anway-catalog`，选 **Public**，Create
2. **Add file → Upload files**：把 `site` 目录**里面的内容**全部拖进去（不要拖 `site` 文件夹本身），Commit changes
3. 仓库 **Settings → Pages**：
   - Source 选 **Deploy from a branch**
   - Branch 选 `main`，目录选 **/(root)**，Save
4. 等约 1 分钟，地址是：

```
https://<你的用户名>.github.io/anway-catalog/
```

5. 手机打开该地址 → 浏览器菜单 → **添加到主屏幕**（iOS 用 Safari「分享 → 添加到主屏幕」）

> 如果把整个 `site` 文件夹上传成子目录，地址会多一层 `/site/`，所以建议只上传里面的文件。

## 五、更新内容（一键）

1. 改 xlsx 的「产品矩阵」表并保存
2. 双击工作区里的 **`3_一键更新数据.bat`**
3. 它会自动做三件事：
   - 重新生成 `site/data.js`、`site/data.json`
   - 在工作区建好 `上传到GitHub` 文件夹，放进要传的文件并打开
   - 浏览器自动打开 GitHub 的上传页面
4. 把 `data.js`、`data.json`、`sw.js` 三个文件拖进网页 → 点 **Commit changes**
5. 约 30 秒后手机刷新，即是新数据

数据文件已设为「联网时总取最新」，所以**不用再改缓存版本号**；断网时回退到上次缓存。

只有改了样式、图标、界面逻辑（`styles.css` / `app.js` / `icons/`）时，才需要额外上传对应文件。

## 六、注意事项

- **只放能对外的信息**：报价、客户名单、未发布型号、内部路线图不要放进公开仓库
- **认证口径**：页面上的认证是平台级信息，带 `*` 的需按型号以证书 / CDF / 报告为准
- 「添加到主屏幕」需要 https（GitHub Pages 满足）；本地 `file://` 只能浏览，不能安装
- 数据来源：安规官网产品页，2026-11-03 复核；型号数以 xlsx 实际行为准（当前 62 个）

## 七、样品需求流程（客户侧）

1. 列表页每个型号右边的 **「+」**，或详情页底部 **「加入样品清单」**
2. 右上角购物车图标显示已选型号数
3. 点购物车进清单：调数量、删型号
4. 填写客户信息（**选填**，填了回复更快）
5. 点 **「提交样品需求」**，三选一发送：
   - **用邮件发送**：打开客户自己的邮箱（收件人已填 `sales@anwayelec.com`，正文是完整需求单）
   - **加企微发需求**：显示二维码，客户扫码加好友，并可一键复制需求单
   - **复制需求单**：粘贴到微信 / WhatsApp / 任何渠道
6. 需求单中英文跟随客户选择的界面语言

客户填的信息和清单只存在**客户手机本地**（localStorage），换设备不会同步，也不上传到任何服务器。

### 替换企微二维码

把你们的企微二维码图片存成 `site/icons/wecom-qr.png`（正方形，建议 ≥400×400），重新上传这个文件即可覆盖。当前已是真实二维码。

### 改收件邮箱

收件人写死在 `site/app.js` 顶部附近的 `var EMAIL = "sales@anwayelec.com";`，改成别的邮箱后重新上传 `app.js`。

## 八、页面地址规则（便于直接分享某个筛选）

| 地址 | 含义 |
|---|---|
| `#/` | 首页 |
| `#/models` | 全部型号 |
| `#/models?s=eco` | 只看 ECO 系列 |
| `#/models?t=triac` | 只看可控硅调光 |
| `#/models?p=b10_30` | 功率 10–30W |
| `#/models?c=enec` | 含 ENEC 认证 |
| `#/models?q=24CV` | 关键词搜索 |
| `#/model/ECO-350G30` | 直接打开某个型号 |

参数可组合，例如 `#/models?s=as-cv&p=b30_60&o=power-desc`。
